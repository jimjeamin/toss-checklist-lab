# 토스 미니앱 실습실

이 폴더는 앱인토스 미니앱 개발을 배우고 테스트하기 위한 작업 공간입니다.

## 테스트 웹사이트

체크리스트는 항목 추가·완료·삭제, 완료 항목 일괄 삭제, 전체/남은 일/완료 필터, 진행률, 브라우저 저장을 지원합니다. 공유 버튼은 기본 모드에서 모의 SDK로 공유 문구를 보여줍니다.

### 로컬에서 사용하기

`preview.html`을 더블클릭해서 브라우저에서 바로 볼 수 있습니다. Vite와 앱인토스 SDK가 필요한 실제 프로젝트 구동은 npm이 설치된 환경에서 `npm install` 후 `npm run dev`를 사용합니다.

### GitHub Pages

저장소 이름을 `toss-checklist-lab`으로 만들고 `main` 브랜치에 push하면 GitHub Actions가 빌드 후 Pages에 배포하도록 설정되어 있습니다. 저장소 Settings → Pages → Build and deployment에서 Source를 **GitHub Actions**로 선택해야 첫 배포가 시작됩니다.

공개 사이트는 교육용이며 토스 앱과 연결되지 않습니다. 공유는 모의 동작입니다.

## 진행 순서

1. 미니앱 아이디어와 대상 사용자를 정합니다.
2. WebView 기반 미니앱의 구조와 앱인토스 SDK 3.x 사용법을 익힙니다.
3. 토스 앱 전용 기능을 로컬에서 안전하게 확인할 수 있도록 SDK 호출부를 분리하고 테스트 대체 동작을 둡니다.
4. 필요한 서버 API가 있으면 서버에서만 비밀 키를 보관하는 방식으로 연동합니다.
5. 로컬 브라우저에서 화면과 기본 흐름을 확인합니다.
6. 개발자 콘솔에 번들을 업로드하고, 테스트용 앱스킴/QR을 이용해 토스 앱에서 최종 확인합니다.

## 모듈 구성

- `src/domain/checklist.ts`: 체크리스트 데이터, 브라우저 저장, 공유 메시지 생성
- `src/platform/share.ts`: 공유 기능의 모의 어댑터와 실제 앱인토스 SDK 어댑터
- `src/main.ts`: 화면 이벤트와 앱 상태를 연결

로컬 기본값은 모의 모드입니다. `VITE_AIT_USE_NATIVE_SDK=true`를 설정하면 실제 SDK 어댑터를 선택하지만, 호출 성공 여부는 토스 앱의 네이티브 브리지에 달려 있습니다. 환경변수만 켜도 브리지가 생기거나 토스 앱 테스트가 가능한 것은 아닙니다.

## 학습 메모

- Client SDK: 토스 앱 안의 WebView에서 로그인, 공유, 기기 기능처럼 앱 기능을 요청합니다.
- Server API: 서버가 인증된 비밀 정보를 사용해 결제 상태 조회 등 서버 측 작업을 수행합니다.
- 비밀 키나 토큰을 브라우저 코드, 저장소, 화면에 노출하지 않습니다.
- 출시 전 테스트에는 공개용 `intoss://`가 아니라 업로드 후 생성되는 `intoss-private://` 테스트 스킴을 사용합니다.

## 현재 실습

체크리스트 공유 버튼은 기본 모드에서 모의 어댑터를 호출하고, 공유 메시지 미리보기를 보여줍니다. 실제 SDK 어댑터는 `Share.sendMessage({ message })`를 호출하도록 분리되어 있습니다. 모의 모드에서는 실수로 실제 외부 공유가 실행되지 않습니다.

## 로컬 실행

Node.js와 npm이 설치된 환경에서:

```sh
npm install
npm run dev
```

현재 개발 환경에는 Node.js는 있지만 npm 명령이 없어 여기서 의존성 설치와 실행은 하지 않았습니다.

## 수동 확인 순서

1. `npm run dev`로 실행하고 새 항목을 추가합니다.
2. 일부 항목을 완료 처리한 뒤 진행률이 바뀌는지 확인합니다.
3. 공유 버튼을 눌러 미리보기 메시지에 완료 상태와 항목이 정확히 들어가는지 확인합니다.
4. 새로고침 후 체크리스트가 유지되는지 확인합니다.

이 확인은 화면·데이터 흐름과 SDK 호출 페이로드를 검증하는 로컬 테스트입니다. 토스 네이티브 공유창, 토스 로그인, 결제, 콘솔 업로드를 검증하지 않습니다.

## 토스 앱 테스트

개발자 콘솔에 미니앱을 등록하고 테스트 권한 및 API 키를 받은 다음, 프로젝트의 `appName`을 콘솔에 등록한 앱의 실제 이름과 일치시켜야 합니다. `npx ait deploy`로 번들을 업로드하고 생성된 테스트 스킴/QR로 토스 앱에서 실행합니다.
